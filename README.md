## 기술 스택

- **디자인:** 잉크 + 웜 페이퍼 + 단일 페트롤 그린 액센트의 에디토리얼 스타일. 공유 `assets/petrol.css`로 전 페이지 공통 셸(헤더, 서브메뉴, 카드, 배지)을 통일하고 SVG 라인 아이콘 시스템을 사용
- **폰트:** Pretendard Variable, 코드블록은 JetBrains Mono
- **프론트엔드:** HTML5, CSS3, Vanilla JavaScript
- **상단 헤더:** 공식 Codex 배경 영상 위 딥 페트롤에서 잉크로 이어지는 그라디언트, 크림 헤드라인
- **CEO 대시보드 예제:** React, Vite, Tailwind CSS
- **호스팅:** Vercel 정적 호스팅 (`docs/` 기준)
