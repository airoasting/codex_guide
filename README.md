## 기술 스택

- **디자인:** 인덱스는 클린 화이트 + 라벤더 블루 카드의 평면 스타일(뉴모피즘 제거), SVG 라인 아이콘 시스템, Codex 블루 바이올렛 액센트. 개별 콘텐츠 페이지는 아직 뉴모피즘이며 순차 전환 중
- **폰트:** Pretendard Variable
- **프론트엔드:** HTML5, CSS3, Vanilla JavaScript
- **상단 헤더:** 공식 Codex 배경 영상과 블루 바이올렛 오버레이
- **CEO 대시보드:** React, Vite, Tailwind CSS
- **호스팅:** GitHub Pages

## 버전 히스토리

Codex 가이드는 2026년 5월 31일 **v1.0.0**으로 버전을 새로 시작합니다. 이 날짜를 기준선(v1)으로 삼고, 이후 매주 일요일을 기준 날짜로 그 주의 작업을 묶어 새 버전을 부여합니다. 버전 규칙은 다음과 같습니다.

- **메이저(앞 숫자, 1.x.x):** 사이트 전체 표준화나 큰 방향 전환.
- **마이너(가운데 숫자, x.1.x):** 새 페이지 추가, 새 기능 도입, 큰 디자인 변경.
- **패치(끝 숫자, x.x.1):** 작은 수정, 문구 정리, 부분 보강.

| 버전 | 날짜 (일) | 부제 | 핵심 변경 |
|---|---|---|---|
| v1.0.0 | 2026-05-31 | Codex 가이드 첫 버전, 평면 리디자인 + 라벤더 아이덴티티 | Claude 가이드를 Codex 가이드로 전환하는 기준선을 잡았습니다. 인덱스의 뉴모피즘을 걷어내 클린 화이트 + 라벤더 블루 카드로 전환하고, 이모지 아이콘을 SVG 라인 아이콘 시스템으로 통일했습니다. 진단·핵심 레슨을 브랜드 퍼플로 강조하고, 헤더 배경 영상을 로컬 자체 호스팅으로 옮긴 뒤 연한 라벤더 블루 톤으로 정리했습니다. |
| v1.1.0 | 2026-06-28 | airoasting 콘텐츠 동기화 + 사이트 표준화 | airoasting 원본 기준으로 1단계와 쇼케이스 페이지 본문을 동기화했습니다(``ai-sycophancy.html``, ``ai-hallucination.html``, ``routines.html``, ``showcase.html``, ``showcase-poems.html``, 신규 ``showcase-skills.html``). ``routines.html``을 ChatGPT 예약 작업 기반 자동화 페이지로 재구성하고, 1단계 상단에 기본기·검증 토글을 도입했습니다. 전 페이지에서 참고문헌·더 읽을거리 섹션과 카드 왼쪽 컬러 띠지를 제거하고, 서브 메뉴 글자 크기와 포맷을 통일했으며, 카드 그리드를 콘텐츠 폭에 맞춰 채우도록 바꿨습니다. serif를 걷어내 Pretendard로 통일하고, ``chrome-plugin.html``과 ``instagram-card-news.html``을 삭제한 뒤 관련 링크를 정리했습니다. 안전·법률 섹션은 맨 하단으로 옮겼습니다. ``ai-fluency.html``에는 이전 방식(역할·맥락·작업·예시·출력)과 v5.5 결과 방식(목표·성공 기준·제약·중단 규칙·검증)을 5개씩 세로로 비교하는 키워드 세트 카드와 한 문장 규칙 요약을 추가했고, OpenAI 공식 v5.5 가이드 기반 ``For Leaders`` 섹션(권장 7요소 뼈대와 리더 액션 3장)을 더한 뒤 비교표와 겹치던 섹션을 단일 8행 비교표로 통합하고 카드 호버 애니메이션을 넣었습니다. ``hackathon.html``과 쇼케이스 내비의 해커톤 항목을 삭제하고, ``routines.html`` 제목을 ``자동화``로 바꿨습니다. 서브메뉴가 있는 39개 페이지 전체를 번호·제목·소제목 형식으로 통일했습니다. |
