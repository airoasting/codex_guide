## 기술 스택

- **디자인:** 인덱스는 클린 화이트 + 라벤더 블루 카드의 평면 스타일(뉴모피즘 제거), SVG 라인 아이콘 시스템, Codex 블루 바이올렛 액센트. 개별 콘텐츠 페이지는 아직 뉴모피즘이며 순차 전환 중
- **폰트:** Pretendard Variable
- **프론트엔드:** HTML5, CSS3, Vanilla JavaScript
- **상단 헤더:** 공식 Codex 배경 영상과 진한 라벤더 블루 오버레이, 흰색 헤드라인, 반투명 블루 바이올렛 소개 pill
- **CEO 대시보드:** React, Vite, Tailwind CSS
- **호스팅:** 정적 웹 호스팅

## 버전 히스토리

Codex 가이드는 2026년 5월 3일 **v1.0**을 기준선으로 삼습니다. 매주 일요일마다 그 주의 콘텐츠 개선, 페이지 추가, 디자인 정리, 실습 보강을 한 번에 묶고 버전을 **0.1**씩 올립니다.

|---|---|---|---|

| v1.1 | 2026-05-10 | 진단과 기본기 정리 | `codex-orientation.html`, `ai-levels.html`, `ai-fluency.html`을 중심으로 첫 진입 동선을 다듬었습니다. Codex를 처음 여는 사용자가 현재 수준을 진단하고 프롬프트 기본기를 익힌 뒤 다음 실습으로 넘어갈 수 있도록 설명 순서를 재배치했습니다. |
