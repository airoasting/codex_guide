Codex란?

대화하는 ChatGPT를 넘어, 직접 일하는 코딩 에이전트

이름은 '한 권의 책'에서 왔습니다.

Codex는 본래 두루마리를 대신해 등장한 책 형태의 고대 필사본, 곧 규칙과 지식을 한데 모아 엮은 책을 뜻합니다.

일의 맥락도 한곳에 모여 있지 않습니다. 자료와 데이터, 지난 의사결정, 진행 기록이 여러 파일과 화면에 흩어져 있습니다. Codex는 이렇게 흩어진 조각을 한 권처럼 읽고, 필요한 장을 직접 고쳐 나가는 디지털 실무자에 가깝습니다.

LATIN ORIGIN
Codex
책 형태의 필사본, 규칙과 지식을 묶은 책
이 이름에는 코드와 문서, 실행 결과를 하나의 작업 맥락으로 다룬다는 뜻이 담겨 있습니다.

ChatGPT와 Codex는 무엇이 다른가

둘 다 같은 GPT 모델을 쓰지만, ChatGPT는 대화로, Codex는 실행으로 일합니다.

ChatGPT가 무엇을 할지 함께 정하는 도구라면, Codex는 그 일을 실제로 해내는 도구입니다. 둘은 같은 GPT 모델을 쓰기 때문에 ChatGPT가 익숙하다면 Codex도 금세 손에 익습니다. 다만 어느 쪽이든 결과를 곧장 내보내지는 않습니다. 맡기고, 확인하고, 사람이 승인하는 과정은 그대로 남습니다.

Claude Code를 떠올리면 이해가 빠릅니다

Codex와 Anthropic의 Claude Code는 같은 '코딩 에이전트' 계열입니다. 쓰는 방식이 거의 같습니다.

공통점

일하는 방식이 닮았습니다

  • 프로젝트 전체를 읽고 맥락을 먼저 파악합니다.
  • 파일을 직접 고치고, 필요한 명령을 실행합니다.
  • 터미널·편집기·앱 같은 실제 작업 환경에서 움직입니다.
  • 규칙 문서로 행동을 통제합니다 — Codex는 AGENTS.md, Claude Code는 CLAUDE.md.
  • 사람의 검토와 승인을 전제로 협업합니다.
차이점

만든 곳과 기반 모델이 다릅니다

  • Codex는 OpenAI가 만들었고 GPT-5 계열 모델로 동작합니다.
  • Claude Code는 Anthropic이 만들었고 Claude 계열 모델로 동작합니다.
  • 사용 방식과 철학은 매우 비슷해, 하나를 익히면 다른 하나도 금방 손에 익습니다.
  • 둘 다 '대화형 챗봇'이 아니라 '일하는 에이전트'라는 점이 핵심입니다.

Codex 앱은 여러 에이전트를 한곳에서 지휘하는 작업 환경입니다

Codex는 2025년 4월 CLI로 처음 등장했고, 2025년 5월에는 ChatGPT 안의 Codex와 웹 작업으로 넓어졌습니다. 별도 데스크톱 앱은 2026년 2월 2일 macOS용으로 먼저 나왔고, 2026년 3월 4일 Windows용으로 확장됐습니다.

2022

ChatGPT 공개

  • 11월 30일 GPT-3.5 기반 연구 프리뷰로 ChatGPT가 공개됐습니다. ChatGPT 발표 ↗

자연어로 지시하고 그 결과를 검토하는 업무 방식이 이때부터 널리 퍼지기 시작했습니다.

2023

GPT-4와 긴 문맥의 시작

  • 3월 14일 GPT-4가 공개되며 더 어려운 추론과 이미지 입력이 ChatGPT Plus에 들어왔습니다. GPT-4 발표 ↗
  • 11월 6일 GPT-4 Turbo, GPTs, 더 긴 문맥, 도구 호출 기능이 함께 발표됐습니다. DevDay 발표 ↗

ChatGPT는 단순히 답하는 도구를 넘어, 긴 자료와 맞춤형 업무까지 다루는 도구로 넓어졌습니다.

2024

멀티모달과 추론 모델

  • 5월 13일 GPT-4o가 공개되며 텍스트, 이미지, 음성을 더 빠르게 오갈 수 있게 됐습니다. GPT-4o 발표 ↗
  • 9월 12일 o1-preview와 o1-mini가 ChatGPT에 들어오며 오래 생각하는 모델이 등장했습니다. o1 발표 ↗
  • 10월 canvas와 ChatGPT search가 추가되며 작성, 코드, 검색 작업이 더 분명한 작업 공간을 얻었습니다.

보고 듣고 답하던 모델이, 오래 생각하고 외부 정보를 찾아 작업하는 모델로 발전했습니다.

2025

에이전트와 Codex의 등장

  • 2월 27일 GPT-4.5가 연구 프리뷰로 나왔습니다. GPT-4.5 발표 ↗
  • 4월 16일 o3와 o4-mini가 공개됐고, Codex CLI가 본격화됐습니다. o3 발표 ↗
  • 5월 16일 ChatGPT 안의 Codex와 웹 작업이 공개됐습니다. Codex 발표 ↗
  • 8월 7일 GPT-5가 나왔고, 11월 GPT-5.1, 12월 GPT-5.2로 이어졌습니다. GPT-5 발표 ↗

ChatGPT는 답변을 만드는 도구를 넘어, 파일과 도구를 직접 다루며 긴 작업을 이어 가는 에이전트 환경으로 자리 잡았습니다.

2026

Codex 앱과 GPT-5.5

  • 2월 2일 Codex 앱이 macOS용으로 나왔습니다. Codex 앱 발표 ↗
  • 3월 4일 Codex 앱 Windows 지원이 추가됐습니다. Codex 앱 발표 ↗
  • 3월 5일 GPT-5.4가 ChatGPT, API, Codex로 배포됐습니다. GPT-5.4 발표 ↗
  • 4월 23일 GPT-5.5가 ChatGPT와 Codex로 배포됐습니다. GPT-5.5 발표 ↗

Codex 앱은 여러 작업을 동시에 맡기고, 결과를 검토하고, 이어서 지시하는 독립된 작업 지휘실로 자리매김했습니다.

활용법

Codex는 여러 작업 환경을 오가며 이어서 쓸 수 있습니다

Codex app

작업 지휘실 · 리더 추천

여러 작업을 나눠 맡기고, 진행 상황을 한 화면에서 살펴봅니다. 리더가 가장 먼저 익히기 좋은 환경입니다.

  • 프로젝트별 작업 관리
  • 리뷰와 이어서 작업하기
  • 자동화와 스킬 사용
Codex CLI

터미널 동료 · 개발팀용

주로 개발팀이 쓰는 환경입니다. 내 컴퓨터의 선택한 폴더에서 파일을 읽고, 수정하고, 명령을 실행합니다.

  • 로컬 코드 수정
  • 테스트와 린트 실행
  • Git 작업 보조
IDE extension

편집기 안의 조수 · 개발팀용

개발팀이 코드를 보다가 바로 질문하고, 작은 변경을 요청하고, 그 자리에서 리뷰까지 받는 환경입니다.

  • VS Code 계열 편집기
  • 선택 코드 설명
  • 작은 수정 반복
Codex web

클라우드 위임

저장소를 연결한 뒤 별도 환경에 작업을 맡기고, 돌아온 결과를 바뀐 부분 비교로 검토합니다.

  • 병렬 작업 위임
  • PR 초안 생성
  • 리포지토리 단위 협업

Codex에게는 결과를 검토할 수 있는 일을 맡겨야 합니다

WORK 01

현황 이해

낯선 자료나 시스템을 읽고 핵심 내용과 중요한 부분, 손대면 위험한 지점을 짚어 설명합니다.

WORK 02

빠른 프로토타입

머릿속 아이디어를 실제로 눌러 볼 수 있는 화면으로 빠르게 만들어, 회의 전에 감을 잡게 합니다.

WORK 03

사내 도구 제작

대시보드, 입력 폼, 관리자 화면처럼 범위가 분명한 도구를 만들어 팀의 손을 덜어 줍니다.

WORK 04

반복 업무 자동화

스프레드시트와 이메일, 자료 정리처럼 매번 반복되는 업무를 하나의 작업으로 묶습니다.

WORK 05

자료·문서 정비

안내서와 보고용 요약, 운영 체크리스트를 실제 상태에 맞게 만들고 최신으로 갱신합니다.

WORK 06

문제 진단과 수정

이상 동작이나 오류를 재현 기록을 바탕으로 원인을 좁히고, 고친 뒤 확인 결과를 남깁니다.

안전한 위임

일을 맡기기 전에 위임의 규칙부터 정해야 합니다

비즈니스 리더 체크리스트

일을 맡기기 전에 정할 기준

  • 이 작업의 성공 기준을 한 문장으로 씁니다.
  • 건드리면 안 되는 자료와 데이터 범위를 분리합니다.
  • 작업 전 현재 상태를 되돌릴 수 있게 저장해 둡니다.
  • 결과 확인 기준을 화면, 표, 문서 중 하나로 정합니다.
  • 최종 배포와 외부 발송은 사람이 승인합니다.
팀 운영 기준

반복할수록 좋아지는 규칙

  • 규칙 문서(AGENTS.md)에 프로젝트 원칙과 금지 사항을 적습니다.
  • 일은 작게 나누고, 단계마다 바뀐 부분을 확인합니다.
  • 확인 방법(검수 화면·점검 항목)을 Codex에게 미리 알려줍니다.
  • 잘 통한 요청문은 템플릿으로 저장해 다시 씁니다.
  • 실패한 작업은 원인과 다음 시도를 기록합니다.
첫 30분

처음에는 설치보다 작게 맡겨 보는 경험이 더 중요합니다

01

ChatGPT 계정으로 Codex를 엽니다

Codex는 지원되는 플랜의 ChatGPT 계정과 연결됩니다. 회사 계정으로 쓴다면 워크스페이스 설정과 권한이 먼저 열려 있어야 합니다.

02

작업 환경을 하나 고릅니다

비개발자라면 Codex 앱이나 웹으로 시작하는 편이 쉽습니다. 개발자와 함께 일한다면 CLI나 IDE에서 같은 프로젝트를 열어 두어도 좋습니다.

03

빈 폴더나 복사본으로 첫 실습을 합니다

중요한 업무 폴더를 바로 열지 말고, 연습용 폴더를 하나 따로 만듭니다. 기존 자료를 고칠 때는 복사본에서 시작해 원본을 지킵니다.

04

첫 요청은 작고 검토하기 쉽게 씁니다

요청 하나에 목표와 제한, 확인 기준을 함께 담아 두는 편이 좋습니다.

이 폴더를 먼저 읽고 구조를 설명해 주세요. 아직 파일은 수정하지 마세요. 수정이 필요하면 어떤 파일을 왜 바꿔야 하는지 계획부터 알려주세요.
05

결과를 보고 다음 작업을 맡깁니다

첫 설명이 정확하면 작은 변경 하나를 맡겨 봅니다. 문구 수정, 버튼 링크 변경, README 보강처럼 결과를 바로 확인할 수 있는 일이 좋습니다.

좋습니다. 이제 index.html의 첫 번째 카드 문구만 바꿔 주세요. 레이아웃과 색상은 유지하고, 수정 후 어떤 줄을 바꿨는지 알려주세요.
