왜 만들었나

시작은 코드가 아니라, 질문 하나였습니다

"가장 강력해질 기술을, 누가 어떻게 가져야 하는가." 2015년 한 비영리 연구소가 이 질문을 던졌습니다. 10년 뒤, 그 질문은 리더의 책상 위에서 일하는 도구가 됩니다. 어떻게 거기까지 왔을까요.

OpenAI 창립 2015.12 비영리 연구소

"재정적 수익에 구속되지 않고, 인류 전체에 이롭게"

2015년 12월, 일론 머스크와 샘 알트만을 비롯한 11명이 OpenAI를 세웠습니다. 목표는 한 문장이었습니다. 인공지능을 가장 인류에 이로운 방향으로 발전시키되, 주주가 아니라 모두를 위한 가치를 만든다는 것. 약정된 후원금은 10억 달러였습니다.

ChatGPT Work란?

하나의 ChatGPT 안에서, 맡길 일에 따라 모드를 고릅니다

ChatGPT에는 Chat, Work, Codex가 함께 있습니다. Work는 조사와 분석부터 문서·스프레드시트·프레젠테이션·보고서·Site까지 긴 지식 업무를 맡는 에이전트입니다. Work와 Codex 안내 ↗

Work는 답변이 아니라 산출물을 목표로 합니다.

Chat은 질문, 검색, 아이디어 구상처럼 빠른 대화에 맞습니다. Work는 여러 단계와 자료, 도구가 필요한 긴 업무를 이어서 처리합니다.

목표를 주면 필요한 맥락을 모으고, 접근법을 계획하고, 진행 중에 확인을 요청하며 검토 가능한 완성본을 만듭니다. 웹과 모바일에서는 클라우드로, 데스크톱에서는 허용한 로컬 파일과 앱을 활용해 일할 수 있습니다.

보고서, 시장 조사, 재무 분석, 발표 자료는 Work에 맡기고, 웹사이트 수정, 코드 작성, 테스트, 저장소 작업은 Codex에 맡깁니다. 빠른 질문과 아이디어 구상은 Chat이 가장 가볍습니다. 세 모드 모두 결과를 검토하고 사람이 승인하는 과정은 그대로 남습니다.

Claude를 썼다면 이렇게 구분하면 됩니다

ChatGPT Work는 긴 지식 업무를 맡는다는 점에서 Claude의 에이전트형 작업 환경과 닮았고, Codex는 Claude Code와 같은 코딩 에이전트에 가깝습니다.

활용법

이제 질문은 하나, 무엇을 맡길 것인가

빠른 대화는 Chat, 긴 지식 업무는 Work, 소프트웨어 작업은 Codex에 맡깁니다. 리더에게 필요한 판단은 어떤 결과를 어디에서 완성할 것인가입니다.

  • 보고서와 발표 자료

  • 작업 시작과 확인
  • 중간 질문에 답하기
  • 완성본 빠른 검토

  • 문서와 스프레드시트
  • 프레젠테이션 제작
  • 로컬 자료 정리
Codex

코드와 웹사이트 작업하기

저장소나 프로젝트 폴더를 열어 코드 수정, 테스트, 리뷰, 자동화를 맡깁니다.

  • 웹사이트와 사내 도구
  • 코드 수정과 테스트
  • 저장소 단위 협업

맡길 일은, 결과를 눈으로 확인할 수 있는 일이어야 합니다

WORK 01

현황 이해

낯선 자료나 시스템을 읽고 핵심 내용과 중요한 부분, 손대면 위험한 지점을 짚어 설명합니다.

WORK 02

조사와 분석

여러 출처와 내부 자료를 모아 비교하고, 근거와 불확실성을 구분한 분석 결과를 만듭니다.

WORK 03

보고서와 발표 자료

회의 목적과 독자를 기준으로 문서, 표, 슬라이드를 만들고 검토할 수 있는 완성본으로 정리합니다.

WORK 04

반복 업무 자동화

스프레드시트와 이메일, 자료 정리처럼 매번 반복되는 업무를 하나의 작업으로 묶습니다.

WORK 05

자료·문서 정비

안내서와 보고용 요약, 운영 체크리스트를 실제 상태에 맞게 만들고 최신으로 갱신합니다.

WORK 06

코드와 Site 제작

웹사이트와 사내 도구처럼 소프트웨어 결과가 필요하면 Codex로 이어서 만들고 검증합니다.

안전한 위임

맡기기 전에, 규칙부터

미션을 앞세워 세운 회사가 통제 장치부터 설계했듯, 위임에도 규칙이 먼저입니다.

비즈니스 리더 체크리스트

일을 맡기기 전에 정할 기준

  • 이 작업의 성공 기준을 한 문장으로 씁니다.
  • 건드리면 안 되는 자료와 데이터 범위를 분리합니다.
  • 연결할 파일과 앱은 업무에 필요한 범위로 좁힙니다.
  • 결과 확인 기준을 화면, 표, 문서 중 하나로 정합니다.
  • 최종 배포와 외부 발송은 사람이 승인합니다.
팀 운영 기준

반복할수록 좋아지는 규칙

  • 반복 업무는 프로젝트 지침이나 템플릿에 원칙과 금지 사항을 적습니다.
  • 일은 작게 나누고, 단계마다 바뀐 부분을 확인합니다.
  • 확인 방법과 필요한 근거를 Work에 미리 알려줍니다.
  • 잘 통한 요청문은 템플릿으로 저장해 다시 씁니다.
  • 실패한 작업은 원인과 다음 시도를 기록합니다.
첫 30분

거창한 설치보다, 30분의 실험

거창한 준비보다, 작은 일 하나를 맡겨 결과를 확인하는 30분이 더 많은 것을 알려줍니다.

01

ChatGPT에서 Work를 엽니다

회사 계정에서는 관리자가 Work 사용 권한을 열어야 할 수 있습니다. 보이지 않으면 워크스페이스 설정과 이용 가능한 플랜부터 확인합니다.

02

웹에서 작은 업무 하나를 고릅니다

처음에는 외부 발송이나 원본 수정이 없는 업무가 좋습니다. 회의 자료 요약, 경쟁사 비교, 문서 초안처럼 결과를 바로 검토할 수 있는 일을 고릅니다.

03

필요한 자료만 건넵니다

업무에 필요한 대화와 파일만 올리고, 연결된 앱의 접근 범위도 확인합니다. 민감한 자료와 관계없는 폴더는 처음부터 빼 둡니다.

04

첫 요청은 작고 검토하기 쉽게 씁니다

요청 하나에 목표와 제한, 확인 기준을 함께 담아 두는 편이 좋습니다.

첨부한 회의 자료를 바탕으로 임원용 1쪽 요약을 만들어 주세요. 핵심 결정 3개, 근거, 남은 위험, 다음 행동을 넣어 주세요. 자료에 없는 내용은 추정하지 말고 확인이 필요한 항목으로 구분해 주세요.
05

결과를 보고 다음 작업을 맡깁니다

첫 결과가 정확하면 표나 발표 자료처럼 한 단계 더 큰 산출물로 이어 갑니다. 중요한 사실과 외부 공유 여부는 사람이 마지막에 확인합니다.

좋습니다. 이 요약을 바탕으로 5장 발표 자료를 만들어 주세요. 각 장에는 제목, 핵심 메시지 하나, 근거를 넣고 마지막 장은 다음 행동으로 끝내 주세요. 완성 후 빠진 근거와 사람이 확인할 항목을 따로 알려주세요.
ChatGPT · Work · Codex의 역사

챗봇이 동료가 되기까지

ChatGPT가 세상에 나온 2022년부터 Work가 출시된 2026년까지, 답하던 도구가 일을 완성하는 동료가 된 길입니다.

ChatGPT Work 2026.07.09 정식 출시

Codex의 실행력이 ChatGPT Work로 넓어졌습니다

Codex는 코드와 저장소에서 긴 작업을 수행하는 방법을 보여 줬습니다. Work는 그 기술을 조사, 분석, 문서, 표, 발표 자료 같은 지식 업무로 넓혀 ChatGPT 안에 담았습니다.

2015

비영리로 시작해, 첫 Codex까지

  • 2015년 12월 머스크와 알트만 등 11명이 OpenAI를 비영리로 설립했습니다. 창립 발표 ↗
  • 2019년 이익 상한(capped-profit) 구조로 전환하고, 마이크로소프트가 10억 달러를 투자했습니다. 구조 설명 ↗
  • 2021년 8월 첫 Codex 모델이 공개돼 깃허브 코파일럿의 엔진이 됐습니다. OpenAI Codex ↗

미션을 지키기 위한 구조 실험과 첫 코드 도구가 모두 이 시기에 나왔습니다. 지금의 Codex는 갑자기 등장한 게 아닙니다.

2022

ChatGPT 공개

  • 11월 30일 GPT-3.5 기반 연구 프리뷰로 ChatGPT가 공개됐습니다. ChatGPT 발표 ↗

자연어로 지시하고 그 결과를 검토하는 업무 방식이 이때부터 널리 퍼지기 시작했습니다.

2023

GPT-4와 긴 문맥의 시작

  • 3월 14일 GPT-4가 공개되며 더 어려운 추론과 이미지 입력이 ChatGPT Plus에 들어왔습니다. GPT-4 발표 ↗
  • 11월 6일 GPT-4 Turbo, GPTs, 더 긴 문맥, 도구 호출 기능이 함께 발표됐습니다. DevDay 발표 ↗

ChatGPT는 단순히 답하는 도구를 넘어, 긴 자료와 맞춤형 업무까지 다루는 도구로 넓어졌습니다.

2024

멀티모달과 추론 모델

  • 5월 13일 GPT-4o가 공개되며 텍스트, 이미지, 음성을 더 빠르게 오갈 수 있게 됐습니다. GPT-4o 발표 ↗
  • 9월 12일 o1-preview와 o1-mini가 ChatGPT에 들어오며 오래 생각하는 모델이 등장했습니다. o1 발표 ↗
  • 10월 canvas와 ChatGPT search가 추가되며 작성, 코드, 검색 작업이 더 분명한 작업 공간을 얻었습니다.

보고 듣고 답하던 모델이, 오래 생각하고 외부 정보를 찾아 작업하는 모델로 발전했습니다.

2025

에이전트와 Codex의 등장

  • 2월 27일 GPT-4.5가 연구 프리뷰로 나왔습니다. GPT-4.5 발표 ↗
  • 4월 16일 o3와 o4-mini가 공개됐고, Codex CLI가 본격화됐습니다. o3 발표 ↗
  • 5월 16일 ChatGPT 안의 Codex와 웹 작업이 공개됐습니다. Codex 발표 ↗
  • 8월 7일 GPT-5가 나왔고, 11월 GPT-5.1, 12월 GPT-5.2로 이어졌습니다. GPT-5 발표 ↗

ChatGPT는 답변을 만드는 도구를 넘어, 파일과 도구를 직접 다루며 긴 작업을 이어 가는 에이전트 환경으로 자리 잡았습니다.

2026

ChatGPT Work와 GPT-5.6

  • 2월 2일 Codex 앱이 macOS용으로 나왔습니다. Codex 앱 발표 ↗
  • 3월 4일 Codex 앱 Windows 지원이 추가됐습니다. Codex 앱 발표 ↗
  • 3월 5일 GPT-5.4가 ChatGPT, API, Codex로 배포됐습니다. GPT-5.4 발표 ↗
  • 4월 23일 GPT-5.5가 ChatGPT와 Codex로 배포됐습니다. GPT-5.5 발표 ↗
  • 7월 9일 GPT-5.6 Sol·Terra·Luna가 ChatGPT, Codex, API에 정식 출시됐습니다. GPT-5.6 발표 ↗
  • 7월 9일 Codex 기술을 긴 지식 업무로 확장한 ChatGPT Work가 출시됐습니다. Work 안내 ↗

GPT-5.6은 성능과 비용에 따라 Sol, Terra, Luna로 나뉘고, Work와 Codex는 맡길 업무의 성격에 따라 선택하는 실행 환경이 됐습니다.

10년 전의 질문이 이제 책상 위의 도구가 됐습니다
