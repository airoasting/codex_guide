04
GitHub 업로드
★★★☆☆
▼
프롬프트
1. GitHub.com 아이디 생성 2. New Repository 생성 3. API Key 생성 (프로필 → Settings → Developer Settings → Personal Access Tokens → Tokens Classic) 4. 해당 API Key를 Codex에 주고 파일 업로드(Push) : 절대로 메모리에 저장시키면 안됨, 보안 관리 5. GitHub.com에서 해당 Repo 클릭 → Settings → Pages → Branch에서 main, /root 선택하고 Save 6. 아이디.github.io/Repository명 으로 웹사이트로 접근
기대 효과
git init → commit → push → Pages 배포까지 전 과정을 자연어 한 줄로 완료. 내 작품이 인터넷에 공개되는 순간을 경험합니다.
♦ 프롬프트 엔지니어링 ★ 버전관리 & 배포

★★★☆☆
▼
프롬프트
해당 폴더의 엑셀 파일("피자 매장별 실적 데이터.xlsx")을 탐색적으로 분석해줘. 매출·성장·수익성에서 발견한 핵심 인사이트를 정리하고, 경영진 보고용 Bain/맥킨지 스타일 진단 PPT로 만들어줘.

07
CEO 데일리 브리핑 대시보드
★★★★★
▼
프롬프트
CEO 아침 브리핑 대시보드를 만들어줘. 오늘의 날씨, 환율·마켓, AI 비서가 요약한 업계 뉴스, AI 명언, 오늘 일정을 한 화면에 모은 개인 대시보드야. 중요: API 키 없이도 샘플(mock) 데이터로 완전히 작동하게 만들어줘. 그리고 설정 패널에서 본인 API 키(뉴스·날씨·환율)를 입력하면 실시간 데이터로 전환되도록 해줘. 뉴모피즘 스타일로.
기대 효과
키 없이도 mock 데이터로 완성형 대시보드가 바로 작동하고, 본인 API 키를 연결하면 실시간으로 전환됩니다. "키 없이 완성, 키 있으면 실시간"이라는 실전 앱 설계 패턴을 익힙니다.
