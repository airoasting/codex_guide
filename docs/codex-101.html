Codex란?

채팅 한 번으로 코드와 파일을 다루게 합니다

코딩을 몰라도 한국어로 부탁만 하면 됩니다

Codex는 채팅으로 부탁하면 실제 파일을 만들고 고치고 정리해 주는 도구입니다. 비개발자도 평소처럼 "이렇게 해줘"라고 한국어로 말하면, Codex가 알아서 폴더를 둘러보고 파일을 만들거나 바꿉니다.

이런 걸 부탁할 수 있어요
  • "이 폴더의 엑셀 파일 수십 개를 한 파일로 합쳐줘"
  • "이 CSV에서 중복을 지우고 월별로 정리해줘"
  • "회사 소개용 1페이지 웹페이지를 만들어줘"
  • "이 보고서 폴더를 날짜별로 이름 바꿔 정리해줘"
두 가지 사용 방식

앱 방식 (이 가이드)

Codex 앱 안에서 평소 채팅하듯 한국어로 부탁합니다. 명령어를 외울 필요가 없어 비개발자에게 맞습니다.

  • Codex 앱 실행
  • Code 모드 선택
  • 한국어로 자연어 요청
  • 진행 상황을 채팅 화면에서 확인

터미널(CLI) 방식 (개발자용)

검은 명령창에서 codex로 실행합니다. 슬래시 명령과 자동화가 강력합니다. 다만 개발 환경에 익숙한 사람에게 맞습니다.

  • 터미널(검은 창) 실행
  • codex 명령어 입력
  • 슬래시 명령으로 세밀 제어
  • 자동화 워크플로우에 적합

파일 정리, 엑셀·CSV 가공, 1~3페이지 사내 웹·대시보드, 단발성 데이터 요약처럼 반나절 안에 끝나는 작업에 잘 맞습니다. 결제·로그인이 들어가는 외부 서비스, 대용량 DB, 장기 유지보수 시스템은 개발자와 함께 가는 편이 안전합니다.

설치 프로그램

시작에 필요한 프로그램

필수 둘(Codex 앱, Git), 선택 하나(Python). 대부분 10분이면 끝납니다

1
Codex 앱 필수 다운로드 →

Codex를 쓰는 작업 앱입니다. 이 안에서 모든 작업이 이뤄집니다. 공식 페이지에서 내려받아 설치하고, 로그인·첫 실행 방법은 시작 안내에서 단계별로 다룹니다.

2
Git 필수 다운로드 →

Git은 파일이 바뀐 과정을 시점마다 저장해두는 도구입니다. 작업이 잘못돼도 이전 상태로 한 번에 되돌릴 수 있는 안전망입니다. 깔아두기만 하면 Codex가 알아서 호출합니다. 설치법은 OS마다 다르니 아래에서 내 것을 펼쳐 보세요.

만든 이 2005년 리누스 토르발스(리눅스를 만든 사람) · 소유 특정 회사가 아닌 오픈소스로, 커뮤니티가 관리합니다(현 관리자 유니오 하마노). 저장·공유 서비스인 GitHub(마이크로소프트 소유)과는 다른 프로그램입니다. · 이름 뜻 'git'은 영국 속어로 "멍청하고 고집스러운 사람"을 가리키는 말입니다. 만든 리누스 토르발스가 "내 프로젝트엔 늘 내 이름을 붙인다"며 자신을 빗대 농담처럼 붙인 이름입니다.

Windows Windows에서 Git 설치하는 법
▾
🔍 받기 전, 내 윈도우 사양부터 확인하세요

Git 설치 파일은 노트북에 따라 32-bit, 64-bit, ARM64 세 가지로 나뉩니다. 맞지 않는 파일을 받으면 설치는 되어도 제대로 돌지 않거나 느려집니다. 받기 전에 한 번만 확인하세요.

  • 키보드에서 Windows 키와 Pause/Break 키를 함께 누르세요. Pause 키가 없는 노트북이면 시작 → 설정 → 시스템 → 정보 순서로 들어가도 됩니다.
  • 열린 화면의 "장치 사양" 항목에서 "시스템 종류" 줄을 찾으세요.
  • 그 줄에 적힌 내용을 보고 받을 파일을 고르면 됩니다.

64-bit (대부분 여기)

  • "64비트 운영 체제, x64 기반 프로세서"
  • 최근 5~10년 안에 산 노트북은 거의 다 여기에 해당합니다
  • git-scm.com의 기본 다운로드 버튼을 누르면 이 파일이 받아집니다

32-bit 또는 ARM64

  • "32비트 운영 체제, x86 기반 프로세서"면 32-bit 설치 파일을 받으세요
  • "ARM 기반 프로세서"(예: Snapdragon 노트북)면 ARM64 설치 파일을 받으세요
  • 두 경우 모두 git-scm.com 페이지 아래의 "Other Git for Windows downloads"에서 직접 고르면 됩니다
1
공식 사이트 접속
git-scm.com/download/win에 접속하세요. 위에서 확인한 사양에 맞는 파일을 받으면 됩니다. 64-bit면 메인 버튼을 누르고, 32-bit나 ARM64면 페이지 아래 "Other Git for Windows downloads"에서 고르세요.
2
설치 파일 더블클릭
받은 Git 설치 파일을 더블클릭하세요. 옵션 화면이 여러 번 뜨는데, 모두 Next를 누르고 마지막에 Install을 누르면 됩니다. 기본값이 가장 무난합니다.
3
재부팅하기
"Finish" 화면이 뜨면 닫고, PC를 한 번 재부팅하세요. 그래야 윈도우가 Git을 인식하고 Codex가 바로 불러 씁니다. 이 단계를 건너뛰면 나중에 "Git을 찾을 수 없다"는 오류가 날 수 있습니다.
Git을 따로 열어 봐야 하나요

아니요. 설치만 해두면 됩니다. 작업 중 파일이 잘못됐을 때 Codex한테 "방금 작업 되돌려줘"라고 부탁하면, Codex가 Git을 대신 써줍니다.

Mac Mac에서 Git 설치하는 법
▾

macOS는 Git이 시스템 안에 들어 있어서 별도 다운로드가 필요 없습니다. 처음 한 번만 깔라는 안내를 받아주면 그걸로 끝입니다.

1
터미널 열기
Cmd + Space로 Spotlight를 열고 터미널이라고 치면 검은 창이 뜹니다.
2
한 줄만 치기
아래 한 줄을 복사해 붙여 넣고 엔터를 누르세요. Git이 없으면 맥이 자동으로 설치 창을 띄워줍니다. "설치"를 누르면 됩니다.
Terminal (macOS)
xcode-select --install
"이미 설치되어 있습니다" 메시지가 뜨면

이미 다 됐다는 뜻입니다. 그대로 터미널을 닫으셔도 됩니다. 다음 단계로 가세요.

3
Python 선택

Python은 데이터 처리·분석·자동화에 많이 쓰는 프로그래밍 언어입니다. Codex가 복잡한 계산이나 데이터 작업을 할 때 이 언어로 코드를 짜서 돌립니다. 시작에는 필요 없습니다. 윈도우도 간단한 표 작업은 Python 없이 되지만, 복잡한 데이터 분석까지 시킬 계획이면 아래에서 펼쳐 미리 깔아두세요.

macOS맥은 Python이 이미 깔려 있습니다. 앞서 Git을 설치할 때(Command Line Tools) Python도 함께 들어오므로, 따로 설치할 필요가 없습니다.

만든 이 1991년 귀도 반 로섬 · 소유 특정 회사가 아닌 오픈소스로, 비영리 단체인 파이썬 소프트웨어 재단(PSF)이 관리합니다.

윈도우 설치법 Windows에 Python 설치하는 법
▾

가장 간단한 방법은 터미널 한 줄입니다. 시작 메뉴에서 PowerShell이나 명령 프롬프트(cmd)를 열고 아래를 붙여 넣으세요. 둘 중 아무거나 괜찮습니다. 윈도우 10·11에 기본 내장된 winget이 알아서 받아 설치하고, PATH도 자동으로 잡아줍니다.

PowerShell / cmd (Windows)
winget install -e --id Python.Python.3.13

설치가 끝나면 터미널을 닫았다 다시 열거나 PC를 재부팅하세요. 그래야 Python이 인식됩니다. python --version을 쳐서 버전 번호가 나오면 완료입니다.

winget이 없다고 나오면

python.org/downloads/windows에서 설치 파일을 받아 실행하고, 첫 화면의 "Add python.exe to PATH"에 반드시 체크한 뒤 "Install Now"를 누르세요.

설치를 마쳤다면 꼭 재부팅하세요

특히 윈도우는 Git을 깐 뒤 PC를 한 번 반드시 재부팅해야 합니다. 그래야 윈도우가 Git을 제대로 인식하고, Codex가 바로 불러 씁니다. 이 단계를 건너뛰면 나중에 "Git을 찾을 수 없다"는 오류가 날 수 있습니다. (맥은 재부팅이 필요 없습니다.)

첫 시작

Codex 앱 열고 첫 작업 맡기기

Windows와 Mac 모두 같은 흐름입니다

이제부터는 모든 작업이 Codex 앱 안에서 이뤄집니다. 명령어를 외울 필요 없습니다. 한국어로 부탁만 하면 됩니다.

1
작업 폴더 미리 만들어두기
바탕화면이나 문서 폴더에 빈 폴더를 하나 만드세요. 예를 들어 codex-test라는 이름이면 됩니다. 이 폴더가 Codex의 작업 공간이 됩니다.
2
Codex 앱 실행
앱을 켭니다. 채팅 화면이 뜨면 됩니다.
3
Code 모드 켜기
작업할 프로젝트를 열고 Codex에게 맡길 폴더를 지정하세요. 화면 안내에 따라 접근 권한을 허용하면 됩니다.
4
작업 폴더 알려주기
화면 안내에 따라 1단계에서 만든 폴더를 선택하세요. 폴더를 채팅창에 그냥 끌어 놓아도 됩니다.
5
자연어로 부탁하기
아래 예시를 그대로 복사해 넣어보세요. Codex가 폴더를 둘러보고 답을 줍니다.
첫 부탁 예시
이 폴더에 뭐가 들어 있는지 보고, 내가 여기서 어떤 일을 할 수 있을지 한 문장으로 말해줘.
✅ 답이 돌아오면 끝

Codex가 폴더 안을 둘러보고 답을 주면 첫 실행은 정상입니다. 이제 진짜 작업을 시작할 수 있습니다.

"파일에 접근해도 될까요"

Codex는 파일을 만들거나 바꾸기 전에 매번 물어봅니다. 처음에는 꼼꼼히 읽고 허용하세요. 익숙해진 뒤에 자주 쓰는 동작만 자동 허용으로 바꾸셔도 됩니다.

중요한 파일은 작업 폴더 밖에 두세요

Codex는 알려준 폴더 안에서만 작업합니다. 그래서 건드리면 안 되는 파일은 처음부터 작업 폴더에 넣지 않는 것이 가장 안전합니다. 회사 기밀 문서·계약서·미공개 재무 자료는 별도 폴더에 두세요.

잘 쓰는 법

잘 쓰는 5가지 습관

알아두면 실패 확률을 크게 줄입니다

1
실행 전, 무엇을 만들지부터 정리하기
바로 "만들어줘"라고 하면 안 됩니다. 방향이 잘못된 채로 작업이 시작되면 중간에 되돌리기 어렵습니다. 한국어로 부탁하기 전에, 짧게라도 무엇을 만들지부터 채팅에서 정리하세요.
자세히 보기 멀티 페르소나 검토 + 프롬프트 예시
▾
💡 여러 시각으로 한 번 더 보기

혼자 생각하면 놓치는 부분이 많습니다. Codex에게 기획자, 개발자, 실사용자 세 사람의 시각으로 같은 아이디어를 검토시키면, 빠진 곳이 잘 보입니다.

  • 기획자: 이 기능이 정말 필요한가, 더 간단한 방법은 없는가
  • 개발자: 구현할 때 막히는 부분은 없는가, 예상 복잡도는 어느 정도인가
  • 실사용자: 실제로 쓸 때 불편하지는 않은가, 빠진 것은 없는가

이 방식을 더 깊게 쓰고 싶으면 멀티 페르소나 가이드를 참고하세요.

계획 토론 프롬프트
나는 [만들고 싶은 것]을 만들려고 해. 세 사람의 시각으로 검토해줘: 1. 기획자: 목적과 범위가 적절한지, 더 쉬운 접근법은 없는지 2. 시니어 개발자: 기술적으로 무엇이 필요한지, 함정은 무엇인지 3. 실사용자: 쓰다 보면 뭐가 불편할 것 같은지 토론 후 합의된 최종 계획을 정리해줘.
2
작게 쪼개서 부탁하기
한 번에 너무 많이 요청하면 방향이 틀어져도 되돌리기 어렵습니다. "1단계만 먼저 만들어줘, 확인하고 이어서 진행할게"가 훨씬 안전합니다.
3
시작 전과 잘 된 시점에 백업하기
Codex는 파일을 직접 수정하거나 삭제합니다. 작업 시작 전에 "git commit으로 현재 상태부터 저장해줘"를 부탁하고, 중간 결과가 마음에 들면 그때마다 한 번 더 같은 부탁을 하세요. 다음 작업이 잘못돼도 여기까지는 안전하게 돌아올 수 있습니다.
4
구체적으로 요청하기
"예쁘게 만들어줘"보다 "배경은 흰색, 텍스트는 16px 이상, 버튼은 파란색"이 훨씬 정확합니다. 색, 크기, 동작을 한 줄씩 풀어 적어주세요.
5
중간에 멈추고 개입하기
예상과 다른 방향으로 가면 끝까지 두지 말고 바로 "잠깐, 이 부분은 다시 생각해보자"라고 끊으세요. 빠르게 끊을수록 되돌릴 양이 줄어듭니다.
🚨 잘못됐을 때, 되돌리는 순서
  1. 즉시 멈추고 상태 확인: "작업 중단. 지금까지 수정한 파일 목록을 알려줘"
  2. Git이 있으면 한 줄로 복구: "git으로 마지막 커밋 상태로 되돌려줘"
  3. Git이 없으면 백업에서 복구: 작업 전 백업 폴더에서 원본을 꺼내 덮어쓰세요
  4. 원인 반영 후 재시작: "이번엔 이렇게 하지 말아줘"라는 규칙을 다음 부탁에 미리 적어 다시 요청하세요
예방이 최선

작업 시작 전 "먼저 git commit으로 현재 상태 저장부터 해줘" 한 줄이면 돌이킬 수 없는 사고를 거의 막을 수 있습니다. Git을 몰라도 Codex가 알아서 처리합니다.

트러블슈팅

자주 막히는 곳

설치하거나 첫 실행하다가 멈추면 여기서 먼저 보세요

Codex 앱이 안 열려요 공통

PC를 한 번 다시 켜보세요. 그래도 안 열리면 앱을 한 번 지우고 다시 설치해 보세요.

"확인되지 않은 개발자"라며 실행이 안 됩니다 macOS

맥의 보안 안내입니다. 시스템 설정 → 개인정보 보호 및 보안으로 들어가면 아래쪽에 "Codex를 그래도 열기" 버튼이 있습니다. 그걸 누르면 됩니다.

Codex 작업 메뉴가 안 보입니다 공통

앱이 옛 버전일 수 있습니다. 앱을 한 번 종료했다가 다시 열어보세요. 자동으로 최신 버전으로 올라옵니다.

로그인 화면에서 막힙니다 공통

브라우저에서 한 번 chatgpt.com으로 로그인이 되는지 먼저 확인하세요. 거기서 되면 앱을 껐다 켜시면 보통 풀립니다.

폴더 접근을 허용했는데 Codex가 못 본다고 합니다 macOS

시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더에서 Codex 앱이 해당 폴더에 체크되어 있는지 확인하세요.

폴더 접근을 허용했는데 Codex가 못 본다고 합니다 Windows

OneDrive 동기화 폴더처럼 클라우드와 묶인 폴더는 피하고 평범한 로컬 폴더를 골라보세요.

회사 PC라서 설치가 막힙니다 공통

회사 보안 정책이 외부 앱 설치를 막는 경우입니다. 사내 IT 담당자에게 Codex 앱과 Git 설치를 요청하세요. 두 도구 모두 공식적으로 검증된 프로그램입니다.
