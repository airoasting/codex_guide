Excel에서 ChatGPT가 하는 일

ChatGPT가 워크북 옆 사이드바로 들어옵니다

OpenAI 공식 문서 기준으로 Excel과 Google Sheets용 스프레드시트 네이티브 경험입니다

ChatGPT for Excel은 Microsoft Excel 안의 사이드바에서 열립니다. 여러 시트, 수식, 참조, 가정이 들어 있는 워크북을 만들고, 고치고, 설명하는 일을 자연어로 맡길 수 있습니다.

Excel 파일을 ChatGPT 대화창에 올려 분석하는 방식과 다릅니다. 이 페이지는 Excel 리본의 Add-ins에서 여는 ChatGPT for Excel 흐름을 기준으로 설명합니다.

설치와 권한

Excel의 Add-ins에서 ChatGPT를 추가합니다

개인 계정과 회사 계정 모두 지원되지만, 회사 계정은 관리자가 막아둘 수 있습니다

  1. Microsoft Excel 열기
    데스크톱 Excel이나 웹 Excel을 엽니다.
  2. Home에서 Add-ins로 이동
    리본 메뉴의 Home 탭에서 Add-ins를 엽니다.
  3. ChatGPT 검색
    Microsoft Marketplace에서 ChatGPT를 검색합니다.
  4. Add 후 리본에서 열기
    추가한 뒤 Excel 리본에서 ChatGPT를 엽니다.
  5. ChatGPT 계정으로 로그인
    지원 플랜이 있는 ChatGPT 계정으로 로그인합니다.
관리자 배포

조직이 Microsoft Store 접근을 막아둔 환경이면 Microsoft 365 관리자가 manifest XML 파일을 써서 내부 배포할 수 있습니다. Integrated apps에서 Deploy Add-in을 선택하고 사용자나 그룹에 할당합니다.

큰 수정 전에는 계획을 먼저 받습니다

보존할 것, 바꿀 것, 작업 범위를 한 문장에 넣습니다

이 워크북을 바로 고치기 전에 먼저 계획을 세워 주세요. 목표: 월별 매출 리포트를 임원 보고용으로 정리 보존: 기존 서식, 기존 수식, 원본 데이터 탭 수정 가능: 요약 탭, 차트 탭, 설명 문장 먼저 다음을 표로 알려 주세요. 1. 수정할 탭과 범위 2. 새로 만들 탭 3. 위험한 수식이나 참조 4. 작업 후 내가 검수할 항목
@로 시트를 좁히기

공식 가이드에 따르면 선택한 시트를 @로 언급해 프롬프트 범위를 좁힐 수 있습니다. 큰 파일에서는 "Inputs 탭만", "Summary 탭은 건드리지 마"처럼 범위를 분명히 적으세요.

실무 프롬프트

반복 업무를 프롬프트 세트로 만듭니다

1. 수식 오류 추적

B145 셀 오류의 원인을 찾아 주세요. 참조되는 셀과 수식 체인을 따라가며 설명하고, 수정안 2가지를 제안해 주세요. 기존 구조를 바꾸는 수정안과 최소 수정안을 나눠 주세요.

2. 지저분한 시트 정리

이 시트를 정리해 주세요. 라벨 표기 통일, 중복 행 제거 후보, 빈 값 처리 기준, 깨진 수식 후보를 먼저 표로 보여 주세요. 내가 승인하기 전에는 셀 값을 바꾸지 마세요.

3. 시나리오 탭 생성

Base, Upside, Downside 3개 케이스를 비교하는 새 시나리오 탭을 설계해 주세요. 가격, 전환율, CAC, 매출총이익률을 주요 가정으로 두고 민감도 표 구조와 필요한 수식을 제안해 주세요.

4. 보고용 KPI 요약

세 개 탭의 KPI 추이를 요약해 주세요. 전월 대비 변화, 이상치, 의사결정이 필요한 지표를 구분하고, 임원 보고용 5줄 요약을 만들어 주세요.
검수와 한계

검수 기준을 먼저 정하면 사고가 줄어듭니다

항목확인할 것왜 중요한가
수식참조 범위, 절대 참조, 숨은 시트 연결한 셀 수정이 다른 탭 전체를 흔들 수 있습니다.
숫자합계, 증감률, 단위, 반올림 기준보고서 숫자는 원본과 다시 맞춰야 합니다.
변경 셀ChatGPT가 바꾼 탭과 범위원치 않는 덮어쓰기를 찾는 기준입니다.
고급 기능VBA, 매크로, 복잡한 서식공식 문서는 고급 스프레드시트 기능 지원이 제한될 수 있다고 안내합니다.
대화 기록Excel 사이드바 대화와 ChatGPT.com 대화스프레드시트 대화는 메인 ChatGPT 대화 기록과 분리됩니다.
중요 파일은 복사본에서

공식 가이드도 중요한 작업은 파일을 복제한 뒤 진행하라고 안내합니다. 특히 재무 모델, 예산안, 고객 데이터는 복사본에서 먼저 테스트하세요.

FAQ와 공식 링크

자주 묻는 질문

Q. 누가 쓸 수 있나요?

OpenAI 공식 문서 기준으로 Free, Go, Plus, Pro, Business, Enterprise, Edu, K-12 사용자가 전 세계에서 쓸 수 있습니다. Free와 Go는 제한된 사용량이 붙습니다.

Q. Google Sheets도 같은가요?

Excel과 Google Sheets는 별도 경험이지만, 새 시트 만들기, 기존 시트 질문, 자연어 업데이트 같은 주요 흐름은 비슷합니다.

Q. 회사 앱이나 내부 시스템과 연결되나요?

지원되는 앱은 계정 플랜, 관리자 설정, 사용자 권한, 연결 데이터 소스 권한에 따라 보입니다. 앱이 안 보이면 워크스페이스 관리자에게 확인해야 합니다.

Q. 데이터는 어떻게 처리되나요?

ChatGPT는 답변을 만들기 위해 프롬프트, 첨부 파일, 관련 스프레드시트 맥락을 처리합니다. Microsoft Excel 안에서 실행되므로 Microsoft 약관도 함께 적용됩니다.
