Office에서 ChatGPT가 하는 일

ChatGPT가 PowerPoint와 Excel 옆 사이드바로 들어옵니다

OpenAI 공식 문서 기준으로 PowerPoint와 Excel 안에서 열리는 확장 프로그램(Add-in) 경험입니다

ChatGPT for PowerPoint와 ChatGPT for Excel은 각각 Microsoft PowerPoint와 Excel 안의 사이드바에서 열립니다. 파일을 ChatGPT 대화창에 올리는 방식과 달리, 지금 보고 있는 덱과 워크북 옆에서 슬라이드와 수식을 자연어로 만들고, 고치고, 설명하게 할 수 있습니다.

이 페이지는 리본의 Add-ins에서 여는 두 확장 프로그램 흐름을 한곳에 모아 설명합니다. PowerPoint 쪽은 베타로, Excel 쪽은 Google Sheets와 함께 제공됩니다.

설치와 권한 (공통)

PowerPoint와 Excel의 Add-ins에서 ChatGPT를 추가합니다

설치 절차는 두 앱이 같습니다. 회사 계정은 관리자가 사용을 막아둘 수 있습니다

  1. Microsoft PowerPoint 또는 Excel 열기
    데스크톱이나 웹에서 원하는 앱을 엽니다.
  2. Home에서 Add-ins로 이동
    리본 메뉴의 Home 탭에서 Add-ins를 엽니다.
  3. ChatGPT 검색
    Microsoft Marketplace에서 ChatGPT를 검색합니다.
  4. Add 후 리본에서 열기
    추가한 뒤 앱 리본에서 ChatGPT를 엽니다.
  5. ChatGPT 계정으로 로그인
    지원 플랜이 있는 ChatGPT 계정으로 로그인합니다.
관리자 배포

조직이 Microsoft Store 접근을 막아둔 환경이면 Microsoft 365 관리자가 manifest XML 파일을 써서 내부 배포할 수 있습니다. Integrated apps에서 Deploy Add-in을 선택하고 사용자나 그룹에 할당합니다.

PowerPoint 실무

덱은 내용보다 목적과 청중을 먼저 알려줍니다

큰 수정 전에는 "바로 고치지 말고 계획부터"라고 요청하면 검수하기 쉽습니다

1. 첫 덱 초안

다음 메모와 KPI를 바탕으로 10장짜리 임원 보고 초안을 만들어 주세요. 청중: 대표이사, CFO 목적: 다음 분기 투자 우선순위 승인 발표 시간: 12분 톤: 결론 먼저, 숫자는 보수적으로 먼저 다음을 제안해 주세요. 1. 전체 스토리라인 2. 슬라이드별 제목 3. 각 장에 필요한 근거 자료 4. 발표자가 받을 질문 5개 5. 바로 만들기 전에 확인할 정보

2. 스토리 진단

이 덱의 스토리를 진단해 주세요. 핵심 메시지, 중복 슬라이드, 빠진 근거, 순서가 어색한 부분을 표로 정리해 주세요. 수정은 아직 하지 말고 이유를 먼저 설명해 주세요.

3. 경영진용으로 압축

이 덱을 경영진 보고용으로 더 날카롭게 줄여 주세요. 삭제 후보, 합칠 슬라이드, 액션 타이틀로 바꿀 제목을 표로 정리해 주세요. 결론이 약한 장표는 새 제목을 제안해 주세요.

4. 발표 준비

이 발표자료를 12분 발표로 준비해 주세요. 슬라이드별 말할 순서, 예상 질문 7개, 답변 초안, 시간이 부족할 때 건너뛸 슬라이드를 알려 주세요.
Excel 실무

워크북은 보존 범위와 작업 범위를 먼저 정합니다

선택한 시트를 @로 언급해 프롬프트 범위를 좁힐 수 있습니다

1. 큰 수정 전 계획

이 워크북을 바로 고치기 전에 먼저 계획을 세워 주세요. 목표: 월별 매출 리포트를 임원 보고용으로 정리 보존: 기존 서식, 기존 수식, 원본 데이터 탭 수정 가능: 요약 탭, 차트 탭, 설명 문장 먼저 다음을 표로 알려 주세요. 1. 수정할 탭과 범위 2. 새로 만들 탭 3. 위험한 수식이나 참조 4. 작업 후 내가 검수할 항목

2. 수식 오류 추적

B145 셀 오류의 원인을 찾아 주세요. 참조되는 셀과 수식 체인을 따라가며 설명하고, 수정안 2가지를 제안해 주세요. 기존 구조를 바꾸는 수정안과 최소 수정안을 나눠 주세요.

3. 시나리오 탭 생성

Base, Upside, Downside 3개 케이스를 비교하는 새 시나리오 탭을 설계해 주세요. 가격, 전환율, CAC, 매출총이익률을 주요 가정으로 두고 민감도 표 구조와 필요한 수식을 제안해 주세요.

4. 보고용 KPI 요약

세 개 탭의 KPI 추이를 요약해 주세요. 전월 대비 변화, 이상치, 의사결정이 필요한 지표를 구분하고, 임원 보고용 5줄 요약을 만들어 주세요.
검수와 한계

검수 기준을 먼저 정하면 사고가 줄어듭니다

PowerPoint 확장은 베타라 특히 수동 검수가 필요합니다

항목확인할 것왜 중요한가
스토리결론, 근거, 반론 대응예쁜 장표보다 설득 구조가 먼저입니다.
수식참조 범위, 절대 참조, 숨은 시트 연결한 셀 수정이 다른 탭 전체를 흔들 수 있습니다.
숫자합계, 증감률, 단위, 반올림, 원본 표보고서 숫자는 원본과 다시 맞춰야 합니다.
변경 사항ChatGPT가 바꾼 슬라이드, 탭, 셀원치 않는 덮어쓰기를 찾는 기준입니다.
고급 기능차트, 애니메이션, VBA, 매크로, 복잡한 서식공식 문서는 고급 기능 지원이 제한될 수 있다고 안내합니다.
대화 기록Office 사이드바 대화와 ChatGPT.com 대화Add-in 대화는 메인 ChatGPT 대화 기록과 분리됩니다.
중요 파일은 복사본에서

공식 가이드도 공유하거나 의존하기 전에 주장, 숫자, 인용, 변경 사항을 검토하라고 안내합니다. 재무 모델, 예산안, 고객 데이터, 중요한 덱은 복사본에서 먼저 테스트하세요.

FAQ와 공식 링크

자주 묻는 질문

Q. 누가 쓸 수 있나요?

OpenAI 공식 문서 기준으로 Free, Go, Plus, Pro, Business, Enterprise, Edu, K-12 사용자가 전 세계에서 쓸 수 있습니다. PowerPoint 확장은 베타이고, Free와 Go는 제한된 사용량이 붙습니다.

Q. PowerPoint가 베타라는 말은 무슨 뜻인가요?

기능과 품질이 계속 바뀔 수 있다는 뜻입니다. 생성된 슬라이드는 수동 정리와 검수가 필요할 수 있습니다.

Q. Excel과 Google Sheets는 같은가요?

Excel과 Google Sheets는 별도 경험이지만, 새 시트 만들기, 기존 시트 질문, 자연어 업데이트 같은 주요 흐름은 비슷합니다.

Q. 회사 앱이나 내부 시스템과 연결되나요?

지원되는 앱은 계정 플랜, 관리자 설정, 사용자 권한, 연결 데이터 소스 권한에 따라 보입니다. 앱이 안 보이면 워크스페이스 관리자에게 확인해야 합니다.

Q. 데이터는 어떻게 처리되나요?

ChatGPT는 답변을 만들기 위해 프롬프트, 첨부 파일, 관련 덱·스프레드시트 맥락을 처리합니다. Microsoft Office 안에서 실행되므로 Microsoft 약관도 함께 적용됩니다.
