INTRO

이 실습에서 만들 것

Codex가 업무 결과를 정리한 뒤, PlayMCP 도구로 카카오톡 나와의 채팅방에 보내는 연결을 만듭니다

2026년 5월 30일 기준으로 안전하게 설명할 수 있는 범위는 카카오톡 나와의 채팅방입니다. 친구 채팅방, 단체 채팅방 읽기, 기존 대화 자동 답장은 PlayMCP의 나와의 채팅방 도구와 다른 문제입니다. 그런 작업은 카카오 공식 API 권한, 비즈니스 채널, 상담톡, 알림톡 같은 별도 영역으로 봐야 합니다.

완성하면 Codex에게 “오늘 작업 요약을 카카오톡으로 보내 주세요”라고 말할 수 있습니다. Codex는 먼저 작업 내용을 정리하고, MCP 도구를 호출해 나와의 채팅방에 메시지를 남깁니다. 업무 리더 입장에서는 긴 결과물을 다시 복사하지 않아도 휴대폰에서 바로 확인할 수 있습니다.

다른 영역

친구에게 보내기, 단톡방 읽기, 자동 답장은 이 페이지의 범위가 아닙니다.

STEP 1 · 준비할 것

카카오 계정, PlayMCP, Codex MCP 지원 확인

연결 전에 세 가지가 준비되어 있으면 설정이 빠르게 끝납니다

1
카카오 계정 로그인 준비
PlayMCP는 카카오 계정 권한을 씁니다. 업무 계정과 개인 계정이 나뉘어 있다면 어느 계정의 나와의 채팅방으로 보낼지 먼저 정합니다.
2
PlayMCP 접속
playmcp.kakao.com에 접속해 로그인합니다. 화면 안에서 도구함 또는 Toolbox 메뉴를 찾습니다.
3
Codex MCP 확인
Codex CLI에서는 /mcp로 현재 연결된 MCP 서버를 확인할 수 있습니다. 새 서버는 ~/.codex/config.toml 또는 Codex 앱의 MCP 설정에서 추가합니다.
핵심 기준

PlayMCP가 Codex 전용 버튼을 따로 보여주지 않아도 괜찮습니다. Streamable HTTP 방식의 MCP 서버 URL을 제공하면 Codex 설정에 같은 URL을 넣어 연결할 수 있습니다.

STEP 2 · PlayMCP 도구함 만들기

카카오톡 나와의 채팅방 도구 추가

PlayMCP에서 카카오톡 도구를 도구함에 넣고, 외부 AI 서비스 연결 정보를 확인합니다

1
도구함 생성
PlayMCP에서 새 도구함을 만들고 이름을 정합니다. 예: codex-kakao-work. 업무용으로 쓸 도구만 넣어두면 Codex가 호출할 수 있는 범위가 명확해집니다.
2
카카오톡 나와의 채팅방 추가
도구 목록에서 카카오톡 나와의 채팅방을 찾아 추가합니다. 권한 확인 화면이 나오면 어떤 정보와 동작을 허용하는지 읽고 승인합니다.
3
MCP 연결 정보 확인
도구함의 연결 또는 공유 메뉴에서 MCP 서버 URL, 일회용 연결 토큰, 인증 안내를 확인합니다. 화면에 표시된 값은 계정 권한과 연결되므로 공개 문서나 GitHub에 올리지 않습니다.

화면 이름은 바뀔 수 있습니다. 카카오가 PlayMCP를 계속 확장하고 있으므로, 버튼 이름이 연결, Connect, Toolbox, 도구함처럼 다르게 보일 수 있습니다. 핵심은 카카오톡 나와의 채팅방 도구를 도구함에 넣고, MCP 서버 연결 정보를 받는 것입니다.

STEP 3 · Codex에 MCP 서버 등록

config.toml에 PlayMCP 서버 추가

Codex는 MCP 서버 설정을 앱, CLI, IDE 확장에서 공유합니다

PlayMCP가 서버 URL을 보여주면 Codex 설정 파일에 다음 형태로 추가합니다. 실제 URL은 PlayMCP 화면에서 복사한 값으로 바꿉니다.

[mcp_servers.playmcp_kakao] url = "https://playmcp.kakao.com/your-mcp-url"

인증이 필요한 서버라면 설정을 추가한 뒤 다음 명령으로 로그인합니다.

codex mcp login playmcp_kakao
1
설정 파일 열기
~/.codex/config.toml을 엽니다. 프로젝트 안에서만 쓰고 싶으면 신뢰한 프로젝트의 .codex/config.toml에 넣을 수도 있습니다.
2
서버 추가
[mcp_servers.playmcp_kakao] 테이블을 만들고 PlayMCP URL을 넣습니다. 서버 이름은 나중에 codex mcp login과 /mcp에서 쓰입니다.
3
연결 확인
Codex를 다시 열거나 새 세션에서 /mcp를 입력합니다. playmcp_kakao와 카카오톡 관련 도구가 보이면 연결된 상태입니다.
보안 팁

토큰을 설정 파일에 직접 적어야 하는 방식이라면 환경 변수로 빼는 편이 낫습니다. PlayMCP가 OAuth 로그인을 지원하면 codex mcp login을 우선 사용합니다.

STEP 4 · 첫 테스트

나와의 채팅방에 짧은 메시지 보내기

처음에는 민감한 정보가 없는 짧은 문장으로 도구 호출을 확인합니다

Codex에게 다음처럼 요청합니다. 도구 목록이 뜨면 카카오톡 나와의 채팅방 도구를 쓰도록 승인합니다.

카카오톡 나와의 채팅방으로 테스트 메시지를 보내줘. 메시지는 "Codex와 PlayMCP 연결 테스트 완료"라고 적어줘.
🔍

Codex 화면

MCP 도구 호출 여부와 승인 요청을 확인합니다. 낯선 도구가 뜨면 중단합니다.

📱

카카오톡 화면

휴대폰 또는 데스크톱 카카오톡의 나와의 채팅방에 메시지가 왔는지 확인합니다.

📝

업무 테스트

테스트가 끝나면 회의 요약, 오늘 변경 파일, 다음 액션 같은 짧은 업무 메시지를 보내 봅니다.

실무에서 바로 쓰는 요청 예시

오늘 이 프로젝트에서 바꾼 내용을 5줄로 요약하고, 내가 내일 확인해야 할 항목 3개를 붙여서 카카오톡 나와의 채팅방으로 보내줘.
STEP 5 · 운영 기준

업무용으로 쓸 때의 안전 장치

메신저 연결은 편하지만, 한 번 보내면 되돌리기 어렵습니다

1
승인 후 전송
처음 운영할 때는 모든 카카오톡 전송 도구를 승인 후 실행으로 둡니다. 자동 승인으로 바꾸기 전에 메시지 형식과 민감 정보 필터를 충분히 확인합니다.
2
보낼 수 없는 정보 정하기
주민등록번호, 고객 전화번호, 계약 금액, 내부 비밀번호, 비공개 링크처럼 메신저로 보내면 안 되는 항목을 AGENTS.md나 프로젝트 지침에 적어둡니다.
3
짧은 보고 형식 고정
나와의 채팅방에는 긴 원문보다 제목, 핵심 요약, 다음 액션, 링크만 보내는 편이 좋습니다. 상세 내용은 GitHub, 문서, 대시보드 같은 원본 위치에 둡니다.

권장 운영 문구: “카카오톡으로 보낼 때는 먼저 초안을 보여주고, 내가 승인한 뒤에만 전송합니다. 고객 개인정보, 계약 금액, 비공개 토큰은 보내지 않습니다.” 이 문장을 프로젝트 지침에 넣어두면 실수 가능성이 줄어듭니다.

FAQ · 자주 막히는 지점

연결이 안 될 때 점검 순서

PlayMCP, 카카오 권한, Codex MCP 설정을 차례대로 확인합니다

Q1. PlayMCP 화면에 Codex 버튼이 보이지 않습니다

Codex 전용 버튼이 없어도 MCP 서버 URL이 있으면 연결할 수 있습니다. URL이 보이지 않으면 PlayMCP의 외부 AI 서비스 연결, 도구함 공유, MCP 연결 메뉴를 확인합니다.

Q2. Codex에서 MCP 서버가 보이지 않습니다

~/.codex/config.toml의 서버 이름과 URL을 다시 확인합니다. 설정을 바꾼 뒤에는 새 Codex 세션에서 /mcp를 입력해 목록을 봅니다.

Q3. 메시지가 보내지지 않습니다

카카오 계정 권한이 만료됐거나 PlayMCP 도구함에서 카카오톡 도구가 빠졌을 수 있습니다. PlayMCP에서 다시 로그인하고, 카카오톡 나와의 채팅방 도구가 활성화되어 있는지 확인합니다.

Q4. 친구나 단톡방으로도 보낼 수 있나요?

이 페이지는 나와의 채팅방 기준입니다. 친구 발송, 단톡방 읽기, 자동 답장은 권한과 정책이 다른 영역입니다. 고객 알림은 알림톡이나 비즈메시지, 상담 자동화는 카카오톡 채널과 상담톡을 별도로 검토해야 합니다.
