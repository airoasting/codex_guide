ChatGPT가 PowerPoint 옆 사이드바로 들어옵니다

OpenAI 공식 문서 기준으로 PowerPoint 안에서 열리는 베타 경험입니다

ChatGPT for PowerPoint는 Microsoft PowerPoint 안의 사이드바에서 열립니다. 원본 자료로 첫 덱을 만들고, 기존 발표자료를 고치고, 덱의 흐름과 청중 질문까지 점검할 수 있습니다.

PPTX 파일을 ChatGPT 대화창에 올리는 방식과 다릅니다. 이 페이지는 PowerPoint 리본의 Add-ins에서 여는 ChatGPT for PowerPoint 흐름을 기준으로 설명합니다.

설치와 권한

PowerPoint의 Add-ins에서 ChatGPT를 추가합니다

베타 기능입니다. 회사 계정은 관리자가 사용을 막아둘 수 있습니다

  1. Microsoft PowerPoint 열기
    PowerPoint를 엽니다.
  2. Home에서 Add-ins로 이동
    리본 메뉴의 Home 탭에서 Add-ins를 엽니다.
  3. ChatGPT 검색
    Microsoft Marketplace에서 ChatGPT를 검색합니다.
  4. Add 후 리본에서 열기
    추가한 뒤 PowerPoint 리본에서 ChatGPT를 엽니다.
  5. ChatGPT 계정으로 로그인
    접근 권한이 있는 ChatGPT 계정으로 로그인합니다.
관리자 배포

조직이 Microsoft Store 접근을 막아둔 환경이면 Microsoft 365 관리자가 manifest XML 파일을 써서 내부 배포할 수 있습니다. Integrated apps에서 Deploy Add-in을 선택하고 사용자나 그룹에 할당합니다.

첫 덱 만들기

원본 자료와 청중을 먼저 알려줍니다

덱은 내용보다 목적이 먼저입니다

다음 메모와 KPI를 바탕으로 10장짜리 임원 보고 초안을 만들어 주세요. 청중: 대표이사, CFO 목적: 다음 분기 투자 우선순위 승인 발표 시간: 12분 톤: 결론 먼저, 숫자는 보수적으로 먼저 다음을 제안해 주세요. 1. 전체 스토리라인 2. 슬라이드별 제목 3. 각 장에 필요한 근거 자료 4. 발표자가 받을 질문 5개 5. 바로 만들기 전에 확인할 정보
큰 수정 전에는 계획 먼저

공식 가이드는 큰 수정 전에 어떤 슬라이드를 바꿀지 먼저 요청하라고 안내합니다. "바로 고치지 말고 계획부터"라는 문장을 넣으면 검수하기 쉽습니다.

덱 수정 프롬프트

기존 덱은 보존 범위를 먼저 정합니다

1. 스토리 진단

이 덱의 스토리를 진단해 주세요. 핵심 메시지, 중복 슬라이드, 빠진 근거, 순서가 어색한 부분을 표로 정리해 주세요. 수정은 아직 하지 말고 이유를 먼저 설명해 주세요.

2. 리스크 슬라이드 추가

시장 개요 뒤에 리스크 슬라이드 1장을 추가할 계획을 세워 주세요. 이 덱의 스타일을 유지하고, 주변 슬라이드는 바꾸지 마세요. 제목, 핵심 메시지, 본문 bullet, 필요한 데이터 자리표시자를 제안해 주세요.

3. 경영진용으로 압축

이 덱을 경영진 보고용으로 더 날카롭게 줄여 주세요. 삭제 후보, 합칠 슬라이드, 액션 타이틀로 바꿀 제목을 표로 정리해 주세요. 결론이 약한 장표는 새 제목을 제안해 주세요.

4. 발표 준비

이 발표자료를 12분 발표로 준비해 주세요. 슬라이드별 말할 순서, 예상 질문 7개, 답변 초안, 시간이 부족할 때 건너뛸 슬라이드를 알려 주세요.
검수와 한계

베타 기능이라 수동 검수가 필요합니다

항목확인할 것왜 중요한가
스토리결론, 근거, 반론 대응예쁜 장표보다 설득 구조가 먼저입니다.
숫자원본 표, 계산 기준, 날짜수치 오류는 발표 신뢰를 바로 떨어뜨립니다.
디자인템플릿, 폰트, 도형 정렬공식 문서는 템플릿 준수가 완벽하지 않을 수 있다고 안내합니다.
고급 편집차트, 도형, 애니메이션, 복잡한 서식일부 PowerPoint 고급 기능은 제한될 수 있습니다.
대화 기록PowerPoint 사이드바 대화와 ChatGPT.com 대화Office add-in 대화는 메인 ChatGPT 대화 기록과 분리됩니다.
공유 전 최종 점검

공식 가이드는 공유하거나 의존하기 전에 주장, 숫자, 인용, 슬라이드 변경 사항을 검토하라고 안내합니다. 중요한 덱은 복사본에서 먼저 작업하세요.

FAQ와 공식 링크

자주 묻는 질문

Q. 누가 쓸 수 있나요?

OpenAI 공식 문서 기준으로 Free, Go, Plus, Pro, Business, Enterprise, Edu, K-12 사용자가 전 세계에서 베타로 쓸 수 있습니다. Free와 Go는 제한된 사용량이 붙습니다.

Q. 베타라는 말은 무슨 뜻인가요?

기능과 품질이 계속 바뀔 수 있다는 뜻입니다. 생성된 슬라이드는 수동 정리와 검수가 필요할 수 있습니다.

Q. 회사 앱이나 내부 시스템과 연결되나요?

지원되는 앱은 계정 플랜, 관리자 설정, 사용자 권한, 연결 데이터 소스 권한에 따라 보입니다. 앱이 안 보이면 워크스페이스 관리자에게 확인해야 합니다.

Q. 데이터는 어떻게 처리되나요?

ChatGPT는 답변을 만들기 위해 프롬프트, 첨부 파일, 관련 발표자료 맥락을 처리합니다. Microsoft PowerPoint 안에서 실행되므로 Microsoft 약관도 함께 적용됩니다.
