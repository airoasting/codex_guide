# codex-orientation.html 스토리텔링 개편 설계

작성일: 2026-06-26
대상 파일: `codex-orientation.html`
목표 등급: 비즈니스 리더 관점 9.5~10점

## 왜 (문제 진단)

현재 페이지는 정확하지만 "설명서"다. 정의 카드 → 비교표 → 연표 → 체크리스트로
정보는 충분하나 세 가지가 없다.

1. 인간의 이야기 — 동기, 갈등, 아이러니가 없다.
2. 연결 조직 — 섹션이 나열될 뿐 서사 전환이 없다.
3. "그래서 나에게" — 창업 미션이 리더의 책상 위 도구로 이어지는 다리가 없다.

## 핵심 서사 축 (확정)

미션 → 도구.

> 2015년, 한 비영리 연구소가 "AGI를 인류 전체에 이롭게"를 내걸었다.
> 10년 뒤, 그 미션은 당신 대신 일하는 도구가 되어 책상 위에 올라왔다.

이 한 문장이 페이지 전체를 관통한다. 모든 섹션이 이 축의 한 장(章)이다.

## 구조 (섹션 6개)

| 장 | 섹션 ID | 변경 |
|---|---|---|
| Hero | header | 후킹 카피로 교체 (미션→도구 한 문장 + 숫자 한 줄) |
| 0 (신규) | `sec-why` | "왜 이 회사는 이 도구를 만들었나" 신규 섹션 |
| 1 | `sec-codex` | "미션이 도구가 된 순간" 프레임. 비교표·Claude Code 비교 사실 보존 + 전환 문장 |
| 2 | `sec-history` | "대화에서 실행으로" 서사. 2015 기원 행 추가, takeaway 스토리 톤 |
| 3 | `sec-usage` | "리더인 당신의 첫 장면"으로 연결 |
| 4 | `sec-safety` | "미션 우선 회사가 통제를 설계한 방식"과 연결 |
| 5 | `sec-first` | 미션으로 회귀하는 마무리 카피 |

디자인 컴포넌트는 100% 재활용. 새 `sec-why`는 기존 `history-callout` /
`history-row` 스타일을 재사용. 서브메뉴(6칸)와 JS `secIds` 배열만 갱신.
시각 시스템(색·카드·연표 CSS)은 건드리지 않는다.

## sec-why 구성

- 도입: 2015년 12월 창립, 11명 창립자, 미션 문구(2015 원문 / 2018 헌장 구분).
- 알트만의 "왜": verbatim 인용 ("We started OpenAI ... make it broadly beneficial").
- 아이러니 3개 (검증된 사실):
  1. $1B 약정, 실제 수령 ~$1.33억(2021 기준).
  2. AI 안전 위해 머스크와 함께 세웠으나 2018년 2월 결별.
  3. "Codex"란 이름은 2021년 태어나 2023년 폐기, 2025년 부활.
- 드라마 한 장면 (강도: 장면 하나로): 2023년 11월 해임 → 800명 서명 → 5일 만 복귀.
  "이 회사가 무엇을 지키려 했는가"로 미션과 연결. 별도 타임라인/접어두기 없음.
- 관통선 인용 (verbatim): "in 2025, we may see the first AI agents 'join the
  workforce'" → 그게 Codex라는 연결.

## 사실/출처 원칙 (AGENTS.md 무날조 준수)

tier-1 출처만 사용: openai.com, blog.samaltman.com/reflections, Wikipedia,
TechCrunch/CNBC/Axios/WaPo. 표기 규칙:

- 창립일: "2015년 12월" (12/8 vs 12/11 출처 상이).
- 미션 문구: 2015 원문("benefit humanity as a whole, unconstrained by a need
  to generate financial return")과 2018 헌장("ensure that AGI benefits all of
  humanity")을 구분.
- 안전 동기는 직접 인용 대신 요약 처리(단일 verbatim 미확보).
- 신규 사실은 참고문헌 섹션에 출처 링크 추가.

## 작업 순서

1. 신규 `sec-why` 섹션 작성.
2. Hero 카피 + 서브메뉴 6칸 + JS `secIds` 갱신.
3. 기존 5개 섹션에 전환 문장·소제목·takeaway 스토리 톤 주입.
4. 연표에 2015 기원 행 추가.
5. 참고문헌 섹션에 신규 출처 추가.
6. 브라우저 렌더 검증 (반응형·서브메뉴·앵커 스크롤스파이).
7. 비즈니스 리더 관점 9.5점 자체 채점.
