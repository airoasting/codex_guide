GitHub 저장과 공유

저장소를 만들고, 파일을 올리고, GitHub Pages로 공개합니다

GitHub 저장과 공유 Vercel 배포
0 개념 설명 개요 1 가입하기 STEP 1 2 올리기 STEP 2 3 Pages 공개 STEP 3 4 참고 도움말

GitHub은 프로젝트를 저장하고 공유하는 코드 창고입니다

저장소 주소 https://github.com/내아이디/프로젝트이름 Pages 주소 https://내아이디.github.io/프로젝트이름/

GitHub에서 무엇을 하나요?

GitHub은 프로젝트 파일과 변경 이력을 한곳에 보관합니다. Codex가 만든 결과물을 저장소에 올리면, 작업 기록을 남기고 다른 사람에게 공유할 수 있습니다.

저장소가 필요한 경우

  • 작업 파일을 안전하게 백업하고 싶을 때
  • 수정 전과 후의 기록을 남겨야 할 때
  • 동료와 같은 프로젝트를 함께 봐야 할 때
  • 정적 HTML 사이트를 GitHub Pages로 공개하고 싶을 때

이 페이지에서 끝내는 일

  • 계정 만들기
  • 저장소 만들기
  • Codex로 파일 올리기
  • GitHub Pages 주소 확인하기

STEP 1: GitHub 가입하기

이 단계의 목표

GitHub 계정을 만들고 첫 번째 저장소를 생성합니다

1

github.com 접속 후 Sign up

github.com에 접속해서 Sign up 버튼을 클릭합니다. 이메일, 비밀번호, 사용자명을 입력합니다.

사용자명은 주소에 들어갑니다. 기억하기 쉬운 영문 이름으로 만드세요.

2

새 저장소 만들기

로그인 후 왼쪽 상단 New 버튼을 클릭합니다.

# 저장소 설정 Repository name: my-project ← 프로젝트 이름 입력 Public / Private 선택 ← 공개 또는 비공개 [Create repository] 클릭

Private 저장소로 만들면 본인과 초대한 사람만 볼 수 있습니다.

3

Personal Access Token 발급 가장 까다로운 단계

Codex가 GitHub에 접근하려면 인증 키가 필요합니다. 화면 위치가 바뀔 수 있으니 메뉴 이름을 기준으로 찾으세요.

1
👤

프로필 클릭

우측 상단 프로필 사진 → Settings

2
🔧

Developer Settings

왼쪽 하단 Developer settings 클릭

3
🔑

토큰 생성

Personal access tokens → Tokens classic → Generate new token

# 토큰 설정 Note: codex-access ← 이름 Expiration: 90 days ← 유효기간 Scopes: repo 체크 ← 저장소 접근 권한 [Generate token] 클릭 후 토큰 복사
보안 주의: 이 토큰은 비밀번호와 같습니다. Codex에게 전달할 때 "이 키는 절대 메모리나 파일에 저장하지 마"라고 함께 말하세요.

STEP 2: Codex로 올리기

이 단계의 목표

Codex에서 프로젝트를 GitHub 저장소에 올립니다

시작 전 확인: Codex에서 작업할 프로젝트 폴더가 열려 있어야 합니다. STEP 1에서 발급받은 토큰도 준비하세요.
1

토큰 전달하기

Codex에게 토큰을 전달할 때는 저장 금지 지시를 함께 줍니다.

# Codex에게 이렇게 말하세요 > GitHub Personal Access Token은 ghp_xxxxxxxxxxxx야 > 이 키는 절대 메모리나 파일에 저장하지 마
2

처음 올릴 때

# Codex에게 이렇게 말하세요 > 이 프로젝트를 GitHub에 올려줘 > GitHub 주소는 https://github.com/내아이디/my-project 야

Codex가 필요한 git 명령을 실행합니다. 명령어를 외울 필요는 없습니다.

3

수정한 내용을 다시 올릴 때

하고 싶은 것Codex에게 이렇게 말하세요
변경사항 저장하기"지금까지 바꾼 거 커밋해줘"
GitHub에 올리기"GitHub에 푸시해줘"
최신 코드 받기"GitHub에서 최신 코드 받아줘"
이전 버전으로 돌리기"마지막 커밋 전으로 되돌려줘"

STEP 3: GitHub Pages로 공개하기

이 단계의 목표

GitHub Pages를 켜서 정적 사이트 주소를 확인합니다

GitHub Pages 활성화 3단계

1
⚙️

Settings 클릭

저장소 상단 탭에서 Settings 선택

2
📄

Pages 메뉴

왼쪽 사이드바에서 Pages 클릭

3
🚀

브랜치 선택 후 Save

main 브랜치 선택 후 Save
1~2분 후 공개됩니다

저장소에 올린 HTML/CSS/JS 파일이 바로 웹사이트로 공개됩니다. 주소 형식은 다음과 같습니다.

https://내아이디.github.io/프로젝트이름/

예) 아이디 hong, 저장소 my-site → https://hong.github.io/my-site/

STEP 4: 더 알고 싶다면

꼭 알아야 할 용어

용어뜻쉽게 말하면
push내 컴퓨터에서 GitHub으로 올리기구글 드라이브에 업로드
pullGitHub에서 내 컴퓨터로 받기구글 드라이브에서 다운로드
cloneGitHub 저장소를 통째로 복사공유 폴더를 내 컴퓨터에 복사
commit변경 내용을 로컬에 저장게임 세이브 포인트
branch독립된 작업 공간원본을 복사해 따로 작업
PR코드 변경 검토 요청"이거 확인해주세요" 요청서
fork남의 저장소를 내 계정으로 복사남의 레시피를 내 노트에 복사
conflict같은 부분을 다르게 수정했을 때두 사람이 같은 문장을 다르게 고침
.gitignoreGit이 무시할 파일 목록"이 파일들은 추적하지 마" 목록

워크트리(worktree) · 한 저장소를 여러 폴더에서 동시에 다루기

한 프로젝트에서 진행 중인 일을 멈추지 않고 다른 버전을 확인해야 할 때가 있습니다. 워크트리는 같은 프로젝트의 사본을 여러 폴더로 펼쳐 두는 기능입니다.

핵심 명령어 3가지

# 새 워크트리 만들기 git worktree add ../my-project-fix fix-login # 목록 보기 git worktree list # 정리하기 git worktree remove ../my-project-fix

이제 프로젝트를 저장소에 올려볼 차례입니다

계정 생성, 저장소 생성, Codex 업로드, Pages 공개까지 이 페이지 안에서 마무리합니다.
