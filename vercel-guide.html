Vercel 배포

프로젝트를 배포하고 공개 주소로 확인합니다

GitHub 저장과 공유 Vercel 배포

Vercel은 프로젝트를 웹 주소로 배포하는 서비스입니다

기본 주소 https://내프로젝트.vercel.app/

Vercel에서 무엇을 하나요?

Vercel은 웹 프로젝트를 받아 빌드하고 공개 주소를 만들어줍니다. 서버를 직접 관리하지 않아도 정적 사이트, React 앱, Next.js 앱을 빠르게 띄울 수 있습니다.

Vercel이 필요한 경우

  • 웹앱을 빠르게 공개 주소로 띄워야 할 때
  • Next.js, React, Vite 프로젝트를 자동으로 빌드해야 할 때
  • 수정본마다 미리보기 주소가 필요할 때
  • 별도 서버 관리 없이 서비스를 운영하고 싶을 때

이 페이지에서 끝내는 일

  • 계정 만들기
  • 프로젝트 가져오기
  • 배포 주소 확인하기
  • 수정 후 자동 갱신 흐름 이해하기

STEP 1: Vercel 가입하기

이 단계의 목표

Vercel 계정을 만들고 대시보드에 들어갑니다

1

vercel.com 접속 후 Sign Up

vercel.com에 접속해서 Sign Up을 클릭합니다. 무료 Hobby 플랜으로 시작해도 충분합니다.

회사 계정으로 운영할 프로젝트라면 개인 메일보다 업무용 메일을 쓰는 편이 관리하기 쉽습니다.

2

대시보드 확인

가입 후 대시보드에 들어가면 새 프로젝트를 만들 수 있습니다. 처음에는 프로젝트 목록이 비어 있어도 정상입니다.

확인할 것: 우측 상단의 Add New 버튼이 보이면 준비가 끝난 상태입니다.

STEP 2: 새 프로젝트 가져오기

이 단계의 목표

Vercel에 배포할 프로젝트를 선택하고 빌드 설정을 확인합니다

1

Add New에서 Project 선택

대시보드 우측 상단 Add New를 누르고 Project를 선택합니다. 연결된 코드 저장소나 업로드된 프로젝트 중 배포할 대상을 고릅니다.

2

빌드 설정 확인

정적 HTML이면 기본값으로 두면 됩니다. 프레임워크 프로젝트라면 Vercel이 대부분 자동으로 감지합니다.

# Import 화면 설정 Project Name: my-project ← 프로젝트 이름 Framework Preset: Other ← 정적 HTML이면 그대로 Root Directory: ./ ← 보통 그대로 둠 [Deploy] 클릭

STEP 3: 배포 URL 확인하기

이 단계의 목표

배포가 끝난 뒤 공개 주소로 접속합니다

1

1~2분 대기 후 URL 열기

Deploy를 누르면 빌드가 시작됩니다. 완료되면 Vercel이 기본 도메인을 만들어줍니다.

https://프로젝트이름.vercel.app/

예) 프로젝트 my-site → https://my-site.vercel.app/

2

도메인 연결은 나중에 해도 됩니다

처음에는 기본 주소로 충분합니다. 자체 도메인이 있으면 Settings → Domains에서 연결할 수 있습니다.

STEP 4: 수정 후 자동 갱신 이해하기

이 단계의 목표

새 버전이 들어올 때 Vercel이 다시 배포하는 흐름을 이해합니다

1

새 버전이 들어오면 빌드가 다시 시작됩니다

한 번 연결해두면 프로젝트에 새 변경사항이 들어올 때 Vercel이 빌드와 배포를 다시 실행합니다.

확인할 것: Vercel 대시보드의 Deployments 탭에서 성공, 실패, 진행 중 상태를 볼 수 있습니다.
2

문제가 생기면 로그를 봅니다

배포가 실패하면 실패한 항목을 열고 로그를 확인합니다. 오류 메시지를 Codex에 붙여 넣으면 수정 방향을 빠르게 잡을 수 있습니다.

STEP 5: 더 알고 싶다면

Vercel에서 자주 보는 용어

용어뜻쉽게 말하면
Deploy프로젝트를 웹에 올리는 작업사이트 공개
Build코드를 웹에서 실행할 형태로 만드는 과정출시 전 포장
Domain사용자가 접속하는 주소가게 간판
Preview정식 공개 전 미리 보는 주소검토용 링크
Environment Variable외부에 보이면 안 되는 설정값서비스용 비밀 메모
Rollback이전 배포본으로 되돌리기문제 생기기 전 버전으로 복구
Serverless Function작은 서버 기능을 파일 단위로 실행필요할 때만 켜지는 작은 업무 창구
Edge사용자 가까운 지역에서 응답 처리가까운 지점에서 바로 응대
Framework Preset프로젝트 종류에 맞춘 빌드 기본값자동 설정 템플릿

React와 Next.js는 무엇인가요?

용어 쉬운 설명 대표 사용 사례
React
(리액트)		 웹사이트 화면을 작은 부품으로 나눠 만들고 조립하는 자바스크립트 라이브러리입니다. 같은 화면 부품을 여러 곳에서 다시 쓸 수 있어 개발이 빨라집니다. 대시보드, 서비스 화면, 인터랙티브 웹앱
Next.js
(넥스트JS)		 React 기반 프레임워크입니다. 서버 처리, 자동 라우팅, 이미지 최적화, 검색 노출 같은 기능을 함께 제공합니다. 서비스 웹사이트, 커머스, 콘텐츠 사이트

이제 프로젝트를 웹 주소로 띄워볼 차례입니다

계정 생성, 프로젝트 가져오기, 배포 URL 확인, 자동 갱신 흐름까지 이 페이지 안에서 마무리합니다.
